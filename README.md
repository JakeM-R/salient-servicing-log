# Servicing rule change log (auto lending)

Live tracker of CFPB, FTC and FCC rules and notices touching auto loan servicing, collections, credit reporting and automated borrower calls, pulled from the Federal Register API, with change-management records (what changed, why, owner, approval, rollout plan, evidence) that export to Markdown or CSV.

Live: https://jakem-r.github.io/salient-servicing-log/

`data.json` is a daily snapshot written by the GitHub Action, used only if the live API call fails.

A tracker, not legal advice. Concept by Jake Makking-Robinson. Not affiliated with Salient.
